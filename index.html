About

SNOWE.GPT ver. 0.6 [BETA]

SNOWE is a chatbot that is definitely, 100% made of snow. Do not leave it in the sun.

Ask him to code something and he writes it live in a code box. When he's done you can copy it, download it, or run it (HTML and JavaScript).

SNOWE searches the web when a question needs fresh facts, and shows his sources under the answer. Paste a link and he opens the website and reads it. Click the ▸ arrow above an answer to see every search, page and thought.

Code boxes have ✨ Cooler (SNOWE upgrades the look) and ▶ Run. If the code crashes, press 🔧 Fix with SNOWE.

Be nice to SNOWE to earn SnowCoins, then spend them in the shop on Avalanche, his smartest brain.

Commands (free, they don't use messages): /help /coins /shop /buy /brain

Shortcuts: / jumps to the textbox, Enter sends, Shift+Enter adds a new line. Double-click the big title to rename a chat.

Chats are saved in your browser only.
